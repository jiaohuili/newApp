# newApp · 拍照姿势抽卡

摆拍前抽一张卡，照着拍。共 39 个姿势，分咖啡店、海边、街头、草地、对镜、情侣 6 个场景，其中 11 个是不露脸姿势（背影、手机挡脸、只拍手等构图）。

- 每张卡都有真人示范图，右下角是机位示意小图：圆点是人，相机图标是拍摄位置，颜色表示高度（绿=低机位，蓝=平视，橙=稍俯拍，红=俯拍）。
- 详情里有摆法、机位、要点和适合场景。
- 支持按场景筛选、只看不露脸、收藏（存在浏览器本地）。

示范图均为 AI 生成内容，人物为虚拟形象，页面和每张卡上都标注了「含AI生成内容」。

## 使用

`index.html` 需要和同目录下的 `images/` 文件夹放在一起才能显示图片。直接双击打开即可，或者起一个本地服务：

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```
