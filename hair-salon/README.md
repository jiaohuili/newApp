# 扎个马尾 · 扎头发小游戏

单文件、零依赖，直接打开 `hair-salon/index.html` 就能玩，手机触屏和电脑鼠标都可以。

## 怎么玩

1. **拢发束**：按住头发往下划，划到的发丝会被拢到头顶（共 20 束，拢满进入下一步）。划得太快会留下碎发，影响完整度。
2. **套皮筋**：在头顶发根旁边按住画圈，绕满一圈半就套好，红色进度圈实时反馈。
3. **控松紧**：长按屏幕（或「按住收紧」按钮）逐渐收紧，在绿色区域松手最好。太松马尾会塌；太紧她会皱眉，收到头会喊痛并直接失败。左上角的小头像会实时给出表情。
4. **戴发饰**：转到正面，挑选并搭配发饰，每类一件，再点一次取下：
   - 发带：运动发带、女仆发带、针织发箍、珍珠发箍
   - 蝴蝶结：大红结、樱粉缎带、格纹结、黑丝绒
   - 发夹：星星夹、樱桃夹、珍珠一字夹、爱心 BB 夹
   - 发饰：小雏菊、草莓发绳、珍珠链
   - 兽耳/犄角：猫耳、狐狸耳、兔耳、小恶魔角、独角兽角

扎完会弹出评分卡：发束完整度占 40%，收紧手感占 60%，配一句评语。完成造型后会根据搭配给出风格名，比如「猫耳女仆咖啡店」「元气运动系」「小恶魔奇幻系」。右侧可以随时切换 4 种发色（栗棕、墨黑、蜜橘、雾紫），底部附有这套 UI 的 5 色色板。

## 配色

甜系马卡龙：粉白底 `#FFF5F6`、樱粉 `#F6B8C8`、薄荷绿 `#8FD8C4`、招牌红 `#E8505B`、可可墨 `#4A3540`。薄荷绿这类冷色只用在可交互元素上（当前步骤、选中状态、绿色甜区、手势提示）。

## 技术实现

发丝是 SVG 三次贝塞尔曲线，每束都有「披散」和「拢起」两组控制点，按进度插值做 morph；马尾的长度和体积跟着拢起的比例变化，收紧时变细、上翘，太松时下垂、散开几束。画面全部由代码绘制，没有图片资源。
