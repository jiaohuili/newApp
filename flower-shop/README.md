# 小花店物语 · 包花小游戏

经营一家街角小花店：客人进门说出想要的花和包装纸，你在耐心条耗完之前把花束包好送出去。

直接打开 `flower-shop/index.html` 就能玩，单文件、无依赖，手机和电脑都可以。

## 画面风格

扁平 + 轻 2.5D 的「轻复古治愈风」：原木柜台和地板、豆沙绿墙裙、圆拱窗，低饱和的莫兰迪底色上用高饱和的花做点缀；面板用奶油色和鹅黄色，标题和数字用深色，层次更清楚。

- 微动态：花架和花束里的花轻轻摇曳，窗外斜照进来的阳光里有微尘飘动，咖啡冒热气，猫咪睡觉时在呼吸。
- 生活小物和彩蛋：墙上的日历会翻到当天，收音机可以开关，柜台上有剪刀、牛皮纸卷和丝带。点一下睡在柜台角上的猫「年糕」，它会醒来喵一声，每天第一次还会掉出 ¥5。
- 有生命感：花架上的花偶尔会冒出心情气泡（「晒太阳中」「选我选我」）。客人从门口走进来，站到柜台后面，头上会冒出招呼或催促的话；送完花再走出去。
- 打烊后买的升级会摆进店里：窗台花箱、门口风铃、大号花桶、藤编小凳。

## 玩法

- 客人最多同时排 3 位，点店里的客人就能切换当前订单；订单卡上写着要几枝什么花、用什么包装纸。
- 点花架上的花加进花束，点花束里的花可以拿出来；选好包装纸后按「送给 TA」。
- 花和包装纸都对是三星，再加小费（剩余耐心越多小费越多）；差一点是两星或一星；差太多客人不付钱。耐心条耗完客人会离开，拉低口碑。
- 花会卖完，要花钱进货；每天营业 100 秒（游戏里是 9:00 到 19:00）。
- 第 2、3、4 天依次解锁向日葵、薰衣草、绣球、百合，以及雾霾蓝、墨黑、豆沙绿包装纸；难度也会随天数上升。
- 目标是累计营业额达到 ¥1500。进度自动保存在浏览器里。
