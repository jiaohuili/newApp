# 小花店物语 · 包花小游戏

经营一家街角小花店：客人进门说出想要的花和包装纸，你在耐心条耗完之前把花束包好送出去。

直接打开 `flower-shop/index.html` 就能玩，单文件、无依赖，手机和电脑都可以。

## 玩法

- 客人最多同时排 3 位，点客人切换当前订单；对话气泡里写着要几枝什么花、用什么包装纸。
- 点花架上的花加进花束，点花束里的花可以拿出来；选好包装纸后按「送给 TA」。
- 花和包装纸都对是三星，再加小费（剩余耐心越多小费越多）；差一点是两星或一星；差太多客人不付钱。耐心条耗完客人会生气离开，拉低口碑。
- 花会卖完，要花钱进货；每天营业 100 秒，打烊后可以买升级：等候椅（耐心更长）、大号花桶（进货更多）、门口风铃（客人更多）、花艺橱窗（小费更多）。
- 第 2、3、4 天依次解锁向日葵、薰衣草、绣球、百合，以及雾霾蓝、高级黑、薄荷绿包装纸；难度也会随天数上升。
- 目标是累计营业额达到 ¥1500。进度自动保存在浏览器里。
